# مواعيد الصلاة — تطبيق أندرويد

## إزاي تطلّع ملف الـ APK (من غير ما تسطّب حاجة)
1. ادخل github.com واعمل حساب لو مش عندك.
2. اعمل Repository جديد (زرار + فوق ← New repository)، سمّيه salah واختار Private، ودوس Create.
3. في صفحة الريبو دوس "uploading an existing file"، وفك الضغط عن الملف، واسحب **كل اللي جوه فولدر SalahReminder** (بما فيهم فولدر .github) وارميهم في الصفحة، وبعدين Commit changes.
4. روح لتبويب **Actions** — هتلاقي "Build APK" شغال (حوالي 3-5 دقايق).
5. لما يخلص بعلامة ✓ خضرا، افتحه وانزل تحت عند **Artifacts** ونزّل Salah-APK، وفك الضغط هتلاقي ملف الـ apk.
6. ابعته لموبايلك وسطّبه (هيطلب منك تسمح بالتثبيت من مصادر غير معروفة).

> لو فولدر .github ماترفعش (أحياناً المتصفح بيخفي الفولدرات اللي بتبدأ بنقطة):
> في الريبو دوس Add file ← Create new file، واكتب في الاسم: `.github/workflows/build-apk.yml`
> وانسخ فيه محتوى الملف ده من الفولدر، ودوس Commit.

## أول ما تفتح التطبيق
- اسمح بالإشعارات.
- لو ظهر مربع أصفر فوق، دوس عليه واسمح بالمنبّهات + استثني التطبيق من توفير البطارية (مهم جداً على شاومي وأوبو وريلمي وسامسونج).
- على شاومي/ريدمي كمان: الإعدادات ← التطبيقات ← مواعيد الصلاة ← Autostart = شغّال.

## طريقة بديلة: Android Studio
افتح الفولدر في Android Studio واعمل Build ← Build APK(s).
